# Referências metodológicas

Este pacote foi escrito especificamente para o CrossHost. A organização por skills pequenas, roteamento por descrição, progressive disclosure, regras negativas, dials visuais, scripts de validação e gates de prova foi informada por materiais públicos, especialmente:

- Everything Claude Code — `affaan-m/ECC` — licença MIT;
- Taste Skill — `Leonxlnx/taste-skill` — licença MIT;
- documentação oficial de Agent Skills da OpenAI/Codex;
- documentação oficial de Skills do Claude Code;
- documentação oficial Adobe e repositórios Adobe-CEP.

Não foram copiados textos, código, identidade visual, assets ou interfaces desses projetos. O pacote usa nomes, instruções, arquitetura e critérios próprios do produto CrossHost.
