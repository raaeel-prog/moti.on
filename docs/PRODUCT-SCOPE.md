# Definição do produto

Antes de implementar o plugin final, registre:

## Problema

- Qual tarefa repetitiva será eliminada?
- O fluxo começa no Premiere, no After Effects ou em ambos?
- Qual é o resultado final esperado pelo editor/motion designer?

## Entradas

- clipes selecionados;
- sequência/composição ativa;
- arquivos externos;
- presets;
- texto, imagens, áudio ou dados de uma API.

## Saídas

- cortes, marcadores ou organização de bins;
- composições, layers, keyframes ou expressões;
- efeitos aplicados;
- render/export;
- arquivos, relatórios ou metadados.

## Requisitos operacionais

- Windows, macOS ou ambos;
- versões mínimas dos aplicativos;
- funcionamento offline;
- conta, licença e número de dispositivos;
- atualização automática;
- idioma;
- uso individual, interno ou comercial.

## Critérios de aceite

Para cada função, escreva uma condição verificável. Exemplo:

> Dada uma sequência ativa com clipes selecionados, ao clicar em “Organizar”, o plugin cria bins por câmera, move os itens corretos e permite desfazer tudo em uma única operação.
